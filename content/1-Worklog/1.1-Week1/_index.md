### Week 1 Achievements:

#### Internship orientation
* Successfully adapted to the internship environment and established communication with FCJ members.
* Understood the internship workflow, regulations, and collaboration process.


#### AWS Foundation
* Built a solid understanding of AWS Cloud fundamentals and the relationships between its core service categories.
* Learned the roles and practical use cases of:
  * Compute
  * Storage
  * Networking
  * Database
* Practiced designing cloud architecture diagrams using Draw.io and AWS official architecture icons.
* Became familiar with the AWS Study Group workshop methodology and documentation.

#### AWS Account Administration

* Successfully created and secured an AWS Free Tier account.
* Implemented Multi-Factor Authentication (MFA) to enhance account security.
* Configured IAM users and administrative groups following AWS security best practices.
* Learned how to monitor cloud costs by creating multiple AWS Budget types, including Cost, Usage, Reserved Instance, and Savings Plans budgets.
* Understood the AWS Support workflow by creating and managing a sample Support Case.

#### Identity & Networking 

  * Acquired practical experience in AWS Identity and Access Management (IAM), including permission management using users, groups, policies, and roles.
* Designed and deployed a functional Amazon Virtual Private Cloud (VPC).
* Configured essential networking resources, including:
  * Public Subnets
  * Internet Gateway
  * Route Tables
  * Security Groups
  * NAT Gateway
* Successfully deployed EC2 instances within the VPC environment.
* Gained a basic understanding of hybrid networking through Site-to-Site VPN architecture.

#### Compute & Storage  Services

* Successfully launched and managed Amazon EC2 instances running both Windows Server 2022 and Amazon Linux 2.
* Installed web server environments using LAMP and XAMPP for application deployment.
* Deployed a sample Node.js application and verified its operation on EC2.
* Configured IAM Roles to enable secure communication between EC2 and AWS services without exposing credentials.
* Created and managed Amazon S3 buckets for object storage and basic data management.

### Weekly Reflection

The first week of the internship provided me with a comprehensive introduction to AWS Cloud and the working environment at First Cloud Journey. Through a combination of theoretical learning and hands-on practice, I developed fundamental skills in cloud account management, security configuration, networking, virtual machine deployment, and cloud storage.

Completing the AWS workshops not only strengthened my understanding of how core AWS services interact within a cloud architecture but also improved my confidence in deploying and managing cloud resources. This foundational knowledge will serve as an important stepping stone for exploring more advanced AWS services and cloud solutions in the upcoming weeks.
