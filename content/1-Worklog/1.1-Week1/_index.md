### Achievements

#### Internship Orientation

* Understood the internship regulations, workflow, and reporting process.
* Became familiar with the internship team and the overall eight-week learning roadmap.
* Learned the basic structure of the FCAJ internship reporting website.

#### AWS Fundamentals

* Gained a solid understanding of the basic concepts of Cloud Computing.
* Distinguished between IaaS, PaaS, and SaaS service models.
* Understood the roles of Regions, Availability Zones, and Edge Locations.
* Identified the major AWS service categories.
* Learned to create simple AWS architecture diagrams using Draw.io and AWS Architecture Icons.

#### Security and Identity Management

* Successfully secured an AWS account by enabling Multi-Factor Authentication (MFA).
* Understood the differences between IAM Users, Groups, Policies, and Roles.
* Created an IAM Admin User for daily administrative tasks instead of using the Root User.
* Learned and applied the Principle of Least Privilege when assigning permissions.

#### Cost Management

* Configured an AWS Budget with email cost alerts.
* Learned how to monitor service costs across different AWS services and Regions.
* Understood the importance of deleting unused resources after completing hands-on labs to avoid unnecessary charges.

### Challenges and Solutions

| Challenges | Solutions |
| --- | --- |
| Difficulty distinguishing between IAM Users and IAM Roles | Reviewed the AWS documentation and clarified that IAM Users represent individual identities, while IAM Roles provide temporary permissions for AWS services or applications. |
| Uncertainty when selecting an AWS Region | Chose the Singapore Region (`ap-southeast-1`) because of its proximity to Vietnam and lower network latency. |
| Unfamiliarity with the AWS Billing interface | Explored Bills, Cost Explorer, Budgets, and Free Tier Usage step by step using the official AWS documentation. |

### Weekly Reflection

The first week provided me with a comprehensive introduction to AWS Cloud and the internship environment at First Cloud AI Journey. I gained a solid understanding of AWS Global Infrastructure, identity and access management with IAM, and account security through Multi-Factor Authentication (MFA).

The most valuable lesson I learned this week is that security and cost management should always be prioritized from the very beginning of any cloud project. Configuring AWS Budgets and avoiding the use of the Root User for daily operations helped me establish good cloud governance and security practices that will benefit me throughout the internship.
