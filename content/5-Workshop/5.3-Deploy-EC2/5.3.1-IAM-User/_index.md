# IAM User

## Introduction

To ensure security when managing AWS resources, the project uses an **IAM User** instead of the Root account.

The IAM User is granted permissions to manage the necessary services to deploy the AI Learning Assistant Platform, such as Amazon EC2, Amazon ECR, Amazon S3, Amazon CloudWatch, and AWS Budgets.

---

## Result

Upon completion, the IAM User is ready to deploy and manage the project's AWS resources.
