# IAM User

## Giới thiệu

Để đảm bảo an toàn khi quản lý tài nguyên AWS, dự án sử dụng **IAM User** thay vì tài khoản Root.

IAM User được cấp quyền quản lý các dịch vụ cần thiết để triển khai AI Learning Assistant Platform như Amazon EC2, Amazon ECR, Amazon S3, Amazon CloudWatch và AWS Budgets.

---

## Kết quả

Sau khi hoàn thành, IAM User đã sẵn sàng để triển khai và quản lý các tài nguyên AWS của dự án.
