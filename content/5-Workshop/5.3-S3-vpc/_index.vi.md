# Triển khai Amazon EC2

## Giới thiệu

Trong phần này, chúng ta sẽ triển khai hạ tầng **Amazon EC2** để làm máy chủ chạy **AI Learning Assistant Platform**.

Máy chủ EC2 sẽ được cấu hình với **IAM User**, **Key Pair**, **Security Group**, **Elastic IP** và hệ điều hành **Ubuntu Server 24.04 LTS**. Sau khi hoàn thành, máy chủ sẽ sẵn sàng để cài đặt Docker và triển khai ứng dụng.
